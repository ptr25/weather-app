# 🌦️ Weather Forecast , My Little Weather App

*Checking the skies, one API call at a time! ☁️*

One of my early experiments with **React Native and JavaScript**, where I explored something completely new — fetching real-world information from the internet and displaying it in an app!

Until then, I'd mostly worked on games, animations, and simple interactive applications. This was my introduction to **APIs, asynchronous programming, and connecting a frontend to an external data service**.

It was pretty cool to realize that my app didn't need to know the weather itself. It could just ask another service for the information and display it!

The original application used coordinates near Tokyo, Japan. The location can be changed by updating the latitude and longitude in the code.

## 🔗 How Does It Work?

The app connects to an external weather service through an **API (Application Programming Interface)**.

Instead of collecting weather information ourselves, we send an HTTP request to a weather provider, which returns the data in JSON format.

**The process:**

1. The React Native app opens.
2. JavaScript's `fetch()` sends a request to the weather API.
3. The API returns weather information as JSON.
4. React stores the received data in the component's state.
5. The interface updates to display the temperature, humidity, and conditions.

**APIs used:**

- **Original project:** FreeCodeCamp Weather API (`fcc-weather-api.glitch.me`)
- **Updated version:** [Open-Meteo API](https://open-meteo.com/)

Open-Meteo provides weather data without requiring an API key for standard non-commercial use.

For example, the API might return:

```json
{
  "current": {
    "temperature_2m": 28,
    "relative_humidity_2m": 65,
    "weather_code": 2,
    "wind_speed_10m": 12
  }
}
```

*These are illustrative values, not live weather measurements.*

The application then converts this information into a simple, readable weather display.

##  Running the App

The updated version can be tested using [Expo Snack](https://snack.expo.dev/).

1. Open Expo Snack and create a new project.
2. Paste the updated code into `App.js`.
3. Select the Web preview or use the Android/iOS options.
4. To run it on a phone, install [Expo Go](https://expo.dev/go) and scan the QR code generated by Snack.
5. Make sure you're connected to the internet so the app can fetch weather information.

To change the location in the updated version, modify:

```javascript
const CITY = 'Bengaluru, India';
const LATITUDE = 12.9716;
const LONGITUDE = 77.5946;
```

The original application used an older weather API and class-based React components. The updated version uses Open-Meteo, React Hooks, improved styling, and additional weather information.
